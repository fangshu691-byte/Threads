# Threads投稿テンプレート（①→②→③→④）

## 型の構成

### ①フック（1〜2行）
テーマに関連する「あるある」や意外な気づきを、短く印象的に投げかける。
続きが気になる引きを作る。

### ②共感（あるある）
ペルソナが日常で感じている悩みを具体的に言語化する。
「わかる」と思わせることを最優先にする。

### ③気づき・価値提供
悩みに対する新しい視点や、知っておくと得する情報を提示する。
売り込み感を出さず、あくまで「気づき」として伝える。

### ④LINE誘導
自然な流れで、詳しい話はLINEで聞けることを案内する。
LINE公式アカウントのURLをここに含める。
押しつけがましくなく、軽いトーンで誘導する。

## 出力形式
- post_1: フック
- post_2: 共感（あるある）
- post_3: 気づき・価値提供
- post_4: LINE誘導（URLを含む）

## トーンのルール
- 敬語だが堅すぎない、親しみやすい文体
- 絵文字は控えめ（多用しすぎない）
- 1投稿あたり2〜4行程度を目安にする
